# Live stress run, 2026-10-28

A measurement pass of `tests/scratch_ai_acceptance_tests.md` against the install
that is actually serving, not against a fresh demo root. The earlier write-up
in `run_2026-10-28.md` read the code and a 72-record dry run. This one read the
released dataset, the frozen eval, the audit chain, and the API on
`127.0.0.1:8081`.

Source files already being edited for the cheap P0 holes were not touched, and
this run did not train, did not search the full corpus, did not roll back the
served model, and did not engage the kill switch.
